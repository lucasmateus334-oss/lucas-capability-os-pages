# Lucas Capability OS — Public Home Base

Evidence-driven public surface for the Lucas Capability OS and Capability Lab.

The project explores how AI capabilities can be made understandable, testable, portable and reproducible through explicit evaluation, public documentation and bounded system design.

## What is public

- Sanitized capability status and verification depth.
- Public-facing technical artifacts and documentation.
- Reproducibility and interoperability experiments suitable for public release.
- GitHub Pages presentation layer.

## What remains private

This repository intentionally excludes private source code, execution receipts, credentials, internal evidence, personal data, private documentation and canonical governance artifacts.

## Sponsorship

GitHub Sponsors can support continued work on public evaluations, reproducibility gates, documentation, interoperability experiments and educational releases.

Sponsorship does not grant access to private data, credentials, internal evidence, or authority over technical validation outcomes.

## Publication boundary

- Canonical source: private repository.
- This repository: public presentation snapshot only.
- Runtime authority: none.
- Credentials/secrets: none.
- Publication target: GitHub Pages only.
