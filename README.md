# Lucas Capability OS — Public Home Base

Public, sanitized presentation layer for the Lucas Capability OS Home Base.

This repository intentionally excludes private source code, execution receipts, credentials, internal evidence, private documentation, and canonical governance artifacts. It exists only to host the bounded public interface through GitHub Pages.

## Publication boundary

- Canonical source: private repository.
- This repository: public presentation snapshot only.
- Runtime authority: none.
- Credentials/secrets: none.
- Publication target: GitHub Pages only.

Nota de fluxo — Este repositório publica somente a camada visual sanitizada do Home Base, para permitir hospedagem GitHub-only sem tornar público o núcleo privado do Capability OS. O fluxo é fonte canônica privada → snapshot público delimitado → GitHub Pages.
